# Changelog

Release notes for decant. The release workflow publishes the section for each version as its
GitHub Release notes, so write them for admins.

## 1.0.0

### Changed

- decant is now open source under the Apache License 2.0. See `LICENSE` and the Licence section
  of the README.
- First stable release. There are no changes to how decant works since 0.3.1, and Macs running
  an earlier version update to 1.0.0 as usual.
